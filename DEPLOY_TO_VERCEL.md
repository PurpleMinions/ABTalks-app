# ABTalks final visual update

This version contains the requested orange/red/maroon student experience, 11-day streak confetti,
mechanical keyboard audio, persistent mute/unmute, larger touch targets, and improved mobile spacing.

## Deploy to the existing Vercel project

1. Unzip this project.
2. Open the project folder in Terminal.
3. Run:
   `npm install`
4. Run:
   `npm run build`
5. Deploy:
   `npx vercel --prod`

If you already have the Vercel CLI connected to the ABTalks project, it will deploy the new version.

The public URL in the prompt will **not change automatically** just because the files are changed locally.
A new production deployment is required before that URL shows these changes.
